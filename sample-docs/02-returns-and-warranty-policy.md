# Lumen Trail Outfitters — Returns and Warranty Policy

> Fictional company. All names, numbers and policies in this document are invented for testing a RAG system.

## 1. Returns

- Customers can return any unused product within **45 days** of delivery for a full refund.
- Products must be in their original packaging, with tags attached.
- **Exceptions (no returns):** opened gas canisters, freeze-dried food, and personalized items (e.g. engraved carabiners).
- Used products cannot be returned, but they may be covered by the warranty (section 3).

## 2. How to start a return

1. Go to "My orders" on the website and choose **Request return**.
2. Select the reason. The system generates a return code that starts with `RT-`.
3. Drop the package at any **Servientrega** point within **7 days** of getting the return code. The code expires after that.
4. Return shipping is **free** for orders over COP 250,000. For smaller orders, COP 14,900 is deducted from the refund.

## 3. Refunds

- Refunds are issued to the original payment method within **5 business days** after the warehouse in Funza inspects the package.
- Store credit is issued immediately and adds a **10% bonus** (e.g. a COP 100,000 return gives COP 110,000 in credit).

## 4. Warranty

- Every product has at least a **2-year warranty** against manufacturing defects.
- Products from the in-house brand **"Lumen Trail Pro"** have a **lifetime warranty** on seams, zippers and frames.
- The warranty does not cover normal wear, accidents, or damage from incorrect use (e.g. using a trekking tent as an expedition tent in snow).
- Warranty claims require a photo of the defect and the order number. Claims are answered within **10 business days**.
- If a product can't be repaired, the customer receives a replacement or store credit for the full purchase price.

## 5. Repair program

Lumen Trail runs a repair workshop in Bogotá. Out-of-warranty repairs cost a flat **COP 45,000** for zippers and **COP 60,000** for seam re-taping, plus parts. Average repair time is **12 days**.
